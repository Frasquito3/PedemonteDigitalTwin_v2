## Fuente de verdad

El código, las pruebas y los manifiestos son la fuente de verdad ejecutable. La documentación explica el sistema, pero cualquier cambio de lógica debe actualizar:

- pruebas;
- documento relacionado;
- manifiesto o hash cuando corresponda;
- evidencia de regresión.
